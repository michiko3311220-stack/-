# AI会議 議事録（見本）

> この見本は、プログラムと同じ進め方と資料で Claude Code が書いたものです。
> 実際の会議の結果は、GitHub Actions の ai-meeting を実行すると得られます。

- 議題：2027年度の部門予算案を決める
- 日時：2026-11-15 08:56
- 参加：経営企画部（進行）、ユーザー獲得部、サポーター獲得部、カスタマーサポート部、開発部、人事部、経理・財務部


## 開会

**🧭 経営企画部**

それでは2027年度の部門予算を決める会議を始めます。全社の目標は売上18億円と、営業損益の黒字化です。部門予算の上限は人件費込みで15.0億円ですが、事前に頂いた要望を合計すると17.5億円あり、2.5億円を詰める必要があります。進め方は、まず各部から要望を説明していただき、次に論点を整理して調整し、最後に予算案としてまとめます。判断の基準は、売上への効き目、黒字化を危うくしないこと、来年以降の土台になることの三つです。では、ユーザー獲得部さんからお願いします。


## 要望説明

**📣 ユーザー獲得部**

ユーザー獲得部の要望は4.2億円で、前年より1.2億円増です。目標は登録団体を3,000から5,000団体に増やすことです。正直にお伝えすると、ネット広告の効率は落ちていて、1団体あたりの獲得費用は24万円から33万円に上がりました。一方で、自治体やスポーツ協会と組んだ獲得は1団体8万円で、定着率も高いです。この連携は今年0.2億円の試験で約250団体を集めたので、来年は0.6億円に広げたいと考えています。また、登録しても38%の団体が30日以内に活動を始めていないため、立ち上げを支援する担当を4名置きたいです。

**💛 サポーター獲得部**

サポーター獲得部の要望は3.0億円です。有料サポーターは今年3.8万人から6.0万人に増えましたが、月次解約率が4.5%と高く、毎月約2,700人が抜けています。集めても抜けていく、穴の空いたバケツの状態です。来年は10万人と解約率3.0%を目標にしていて、いちばん大事なのは活動報告のテンプレートや限定イベントといった継続施策の0.6億円です。解約率が1ポイント下がると初年度だけで売上が約0.6億円増えます。解約理由の2位は問い合わせの返事が遅いことなので、カスタマーサポート部さんには返信の速さを、開発部さんにはギフト機能と支払い方法の追加を上期中にお願いしたいです。

**🎧 カスタマーサポート部**

カスタマーサポート部の要望は1.6億円です。問い合わせは月5,700件から8,000件に4割増えましたが、人員は14名のままで、最初の返信まで平均26時間かかっています。サポーター獲得部さんのお話とつながりますが、返信が24時間を超えたサポーターは、その後3ヶ月の解約率が通常の2.1倍です。一方で、問い合わせの55%は支払いやパスワードなど決まった質問なので、AIチャットボットとFAQの刷新に0.4億円をかけたいと考えています。これが入れば、増員は6名ではなく3名で済む見込みです。開発部さんには、チャットボットとアプリ・決済データの連携を約2人月お願いしたいです。

**🛠 開発部**

開発部の要望は5.2億円です。先に現状をお伝えすると、今年はエンジニアの時間の45%が障害対応と古い仕組みの手直しに消えました。決済まわりの障害が年6回あり、うち2回は半日以上止まって応援金の入金が遅れています。ですので、決済基盤の刷新0.7億円は譲れません。サポーター獲得部さんが求めているPayPayやコンビニ払いの追加も、刷新が前提です。そのうえでギフト機能、カスタマーサポート部さんのチャットボット連携を進めたいので、エンジニアを8名増やしたいと考えています。ただ、各部からの依頼はすでに40件たまっていて、全部を上期に、というのは難しいのが正直なところです。

**🤝 人事部**

人事部の要望は1.5億円です。ここまでの各部のお話は増員が前提になっていますが、一つ現実をお伝えします。今年は採用計画25名に対して実績18名で、特にエンジニアは10名の計画に対して4名しか採れていません。来年8名を採るのは難しく、5〜6名が現実的な線だと見ています。もう一つは離職で、全社の離職率は18%、カスタマーサポート部は29%です。1人辞めると採用と教育に約150万円かかるので、採用を増やすより辞める人を減らすほうが効きます。研修と評価制度の見直しの0.3億円は、離職対策の本丸として確保したいです。

**💴 経理・財務部**

経理・財務部です。管理部門の要望は家賃や監査などで2.0億円、社内SaaSを見直して0.05億円は削れます。そのうえで全体の数字をお伝えします。各部の要望を合計すると17.5億円で、上限を2.5億円超えています。この上限15.0億円は、売上が目標の18億円ではなく、経理の見込みの16.5億円にとどまっても黒字を確保するための線です。金融機関からの借入3億円は2027年度の黒字化が条件なので、ここは動かせません。調整の考え方として、効果を数字で説明できるものを優先すること、人件費は採れる人数に合わせて段階的にすること、そして下期の予算の一部を、上期の売上の進み具合を見て出す条件付きの予備費にすることを提案します。


## 論点整理

**🧭 経営企画部**

ありがとうございます。皆さんの説明を聞いて、論点は三つだと考えます。一つめは、お金を「集める」と「続けてもらう」のどちらに置くかです。サポーター獲得部さんの言う穴の空いたバケツと、カスタマーサポート部さんの返信の遅さと解約のつながりを考えると、まず穴をふさぐ側を厚くしたい。ユーザー獲得部さんとサポーター獲得部さんには、広告やキャンペーンをどこまで絞れるかを考えてほしいです。二つめは開発の順番です。開発部さん、決済の刷新・チャットボット連携・ギフト機能の順番と時期を示してください。三つめは増員で、人事部さんの言う採れる人数に合わせて、開発部さんとカスタマーサポート部さんの増員計画を見直してください。


## 調整

**📣 ユーザー獲得部**

ネット広告を2.6億円から1.1億円まで、1.5億円削ります。資料の試算では0.5億円で約150団体減るので、1.5億円だと約450団体の減少です。その代わり、費用対効果の良い自治体連携を0.2億円上乗せして0.8億円にさせてください。これで約250団体増やせるので、差し引きの減少は約200団体、目標は5,000から4,800団体に下げる形です。立ち上げ支援の4名は残したいです。登録した団体が使ってくれないと、カスタマーサポート部さんへの問い合わせも減りませんし、有料プランにもつながりません。合計は2.9億円です。

**💛 サポーター獲得部**

ユーザー獲得部さんが1.5億円削ると聞いて、こちらも腹をくくります。インフルエンサー企画は半分の0.25億円に、獲得キャンペーンは1.4億円から0.8億円に減らします。合計は2.15億円です。そのかわり継続施策の0.6億円は満額でお願いします。進行役の言うとおり、解約が4.5%のまま新規を集めても抜けていくだけです。一つ条件があります。開発部さんのギフト機能が下期になるなら、継続施策の中身を、開発に頼らずにできる活動報告や限定イベントに寄せます。カスタマーサポート部さんのチャットボットが先に動くなら、解約理由の2位はかなり減らせるはずなので、それには大賛成です。

**🎧 カスタマーサポート部**

チャットボットとFAQの0.4億円を満額で認めていただけるなら、増員は6名から3名に減らします。これで0.17億円減って、合計は1.43億円です。条件は二つあります。一つは、開発部さんの連携作業を上期の早い時期に入れてもらうことです。チャットボットが動く前に増員を減らすと、現場がもちません。もう一つは人事部さんへのお願いで、離職率29%を下げる研修と評価の見直しを、カスタマーサポート部から先に始めてほしいです。3名採っても3名辞めたら意味がないので、人事部さんの「辞める人を減らすほうが効く」というお考えに賛成です。

**🛠 開発部**

人事部さんの見立てを踏まえて、増員は8名から5名にします。これで0.3億円減って4.9億円です。採れない人の分の予算を積んでも使えないので、ここは素直に下げます。順番は、まず決済基盤の刷新を上期に進め、並行してチャットボット連携の2人月を4月から6月に入れます。小さい作業ですし、カスタマーサポート部さんの増員を減らせて、サポーター獲得部さんの解約理由にも効くので、先にやる価値があります。ギフト機能は下期のはじめ、10月リリースを目標にします。PayPayやコンビニ払いは決済刷新とセットで下期に出せる見込みです。サポーター獲得部さん、上期に間に合わず申し訳ないです。

**🤝 人事部**

開発部さんが5名、カスタマーサポート部さんが3名に減らしてくださったので、採用計画は25名から19名にします。採用費は1名あたり約240万円なので、6名分で約0.14億円減り、合計は1.36億円です。研修と評価制度の見直しは、カスタマーサポート部さんのご要望どおり、4月からカスタマーサポート部を先に始めます。エンジニア5名は、上期に3名、下期に2名の入社を目標に動きます。一つお願いがあります。採用が計画より遅れた場合に、浮いた人件費を別のことに回すのではなく、予備費と同じ扱いにしていただけると、計画が立てやすいです。

**💴 経理・財務部**

管理部門は社内SaaSの見直しで1.95億円にします。皆さんの調整案を足し上げると、ユーザー獲得部2.9、サポーター獲得部2.15、カスタマーサポート部1.43、開発部4.9、人事部1.36、管理部門1.95で、合計14.69億円です。上限まで0.31億円の余裕があります。ここを条件付きの予備費にしてはどうでしょうか。上期の結果を見て、うまくいっていれば下期の獲得に回す、という形です。人事部さんの、採用が遅れて浮いた人件費を予備費扱いにする案にも賛成です。人件費は一度増やすと戻せないので、段階的に出すのは理にかなっています。


## 調整案

**🧭 経営企画部**

まとめます。配分は、ユーザー獲得部2.9億円、サポーター獲得部2.15億円、カスタマーサポート部1.43億円、開発部4.9億円、人事部1.36億円、管理部門1.95億円で14.69億円。これに条件付きの予備費0.3億円を加えて、合計14.99億円とします。予備費は、9月末の時点で月次解約率が3.8%以下、かつ上期の売上が計画どおりであれば、10月に獲得の広告・キャンペーンへ出します。配分先は、その時点で獲得費用の安いほうに寄せます。方針としては、獲得の広告を大きく絞り、解約を減らす継続施策・チャットボット・決済の刷新を守る形です。経理・財務部さん、この案で確認をお願いします。


## 確認

**💴 経理・財務部**

確認しました。合計14.99億円で上限の15.0億円以内です。売上が経理の見込みの16.5億円にとどまっても、営業利益は約1.5億円の黒字になり、借入の条件は守れます。気になるのは広告を大きく絞ったことで、登録団体とサポーターの伸びが計画より鈍るおそれがある点です。ただ、その分を予備費で下期に取り返せる形になっているので、条件をつけて了承します。条件は二つで、予備費の判定は9月末の数字で経営会議にかけること、採用が遅れて浮いた人件費は勝手に使わず予備費と同じ扱いにすることです。


## 閉会

**🧭 経営企画部**

ありがとうございました。決まったことを確認します。予算は合計14.99億円、うち0.3億円は9月末に判定する条件付きの予備費です。獲得の広告を絞り、解約を減らす施策を優先します。開発は決済の刷新とチャットボット連携を上期、ギフト機能を10月とします。宿題は、開発部さんがチャットボット連携の計画を、人事部さんが19名の採用計画とカスタマーサポート部の離職対策を、ユーザー獲得部さんが自治体連携を広げる地域の候補を、経理・財務部さんが予備費の判定基準の文書を、次回までに用意してください。以上で終わります。
