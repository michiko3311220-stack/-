# 経理・財務部｜課題と目標（2027年度）

## 役割
お金の管理、予算の取りまとめ、資金繰り、金融機関・株主への説明。

## 財務の状況
- 現預金：12.0億円
- 2026年度は営業損失 1.1億円
- 金融機関からの借入（3億円）の条件：**2027年度の営業黒字化**。守れないと追加の借入が難しくなる

## 2027年度の数字の考え方
- 売上目標 18.0億円は「全部うまくいけば」の数字。経理としては **16.5億円で見込む**
- 部門予算の上限 15.0億円は、売上16.5億円でも黒字（+1.5億円）を確保するための線
- 各部の要望合計は **17.5億円**（上限を 2.5億円 超過）

## 共通でかかる費用（管理部門）
- 予算要望：2.0億円（前年 1.8億円）

| 項目 | 金額 |
|---|---|
| 家賃・オフィス | 0.8億円 |
| 社内システム・SaaS | 0.4億円 |
| 監査・税理士・法務 | 0.3億円 |
| 経理・財務部・経営企画部の人件費 | 0.5億円 |

## 経理・財務部の提案
- 効果が数字で説明できるものを優先する
- 人件費は一度増やすと減らしにくい。増員は採れる人数に合わせて段階的に
- 下期の予算は、上期の売上の進み具合を見て出す「条件付き」の枠を作りたい（予備費）

## 削れる点
- 社内SaaSの見直しで ▲0.05億円は可能
