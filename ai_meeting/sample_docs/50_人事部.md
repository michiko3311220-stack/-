# 人事部｜課題と目標（2027年度）

## 役割
採用・育成・働く環境づくり。

## 2026年度の振り返り
- 採用 18名（計画 25名）。エンジニア採用が特に難航（計画10名 → 実績4名）
- 離職率 18%（IT業界平均 12%）。CS部の離職率は 29%
- 退職理由の上位：業務量の多さ、評価への不満、キャリアが見えない

## 課題
- 計画どおりに採れず、各部の増員計画が絵に描いた餅になっている
- 辞める人が多く、採っても人が増えない

## 2027年度の目標
- 採用 25名（エンジニア8名・CS6名・オンボーディング4名ほか）
- 離職率 18% → 13%
- CS部の離職率を 29% → 18%

## 予算要望：1.5億円（前年 1.1億円）
| 項目 | 金額 |
|---|---|
| 採用費（エージェント手数料・採用広報） | 0.6億円 |
| 研修・評価制度の見直し | 0.3億円 |
| 部員の人件費 | 0.4億円 |
| 福利厚生・働く環境の改善 | 0.2億円 |

## 人事部から見た注意点
- エンジニア8名を1年で採るのは現実的に難しい（今年は4名）。5〜6名が現実的な線
- CSは採用より離職を止めるほうが効く。1人辞めると採用・教育で約150万円かかる

## 譲れない点・削れる点
- 譲れない：研修・評価制度の見直し（離職対策の本丸）
- 削れる：採用人数が減れば採用費は1名あたり約240万円ずつ減る
